# Feedback da Comunidade Nuvemshop

Página para lojistas da comunidade Nuvemshop compartilharem seus e-commerces e receberem feedback de outros lojistas.

## Funcionalidades

- **Cadastro de lojas**: Lojistas podem adicionar suas lojas para receber feedback
- **Feedback da comunidade**: Outros lojistas podem deixar comentários e dicas
- **Curtidas**: Sistema de likes para lojas e comentários
- **Busca**: Filtro para encontrar lojas específicas
- **Preview de sites**: Exibe imagem de preview dos sites cadastrados
- **Painel de gestão**: Área administrativa para gerenciamento

## Tecnologias

- HTML5
- CSS3 (Design inspirado no Nimbus Design System da Nuvemshop)
- JavaScript (Vanilla)
- LocalStorage para persistência de dados

## Como usar

1. Abra o arquivo `feedback-comunidade.html` em um navegador
2. Ou hospede em qualquer servidor web estático (GitHub Pages, Vercel, Netlify, etc.)

## Estrutura

```
FeedbackComunidade/
├── index.html                  # Página principal
├── assets/
│   └── logo-nuvemshop.png      # Logo da Nuvemshop
└── README.md                   # Este arquivo
```

## Hospedagem no GitHub Pages

1. Faça upload do repositório no GitHub
2. Vá em Settings > Pages
3. Selecione a branch `main` e pasta `/ (root)`
4. O site estará disponível em `https://seu-usuario.github.io/nome-do-repo/`
